# Koji — хувийн портфолио

React, JavaScript, CSS, Vite ашиглан бие даан бүтээсэн responsive портфолио сайт.

## Ажиллуулах

```bash
npm install
npm run dev
```

Нийтлэх хувилбар үүсгэх:

```bash
npm run build
```

## Сайтын санаа

Гол нүүрийг үйлдвэрийн угсралтын шугам шиг зохиож, бүтээлүүдийг таван станц болгон дүрсэлсэн. Изометр SVG дүрслэл дээр хөдөлгөөнт дамжуурга, горим солих, өнцөг сонгох, чирж эргүүлэх, хүрдээр томруулж/жижигрүүлэх үйлдэлтэй. Станц дээр дарахад тухайн төсөл, танилцуулга эсвэл холбоо барих мэдээлэл гарна. Доош гүйлгэвэл танилцуулга, ур чадвар, төслийн жагсаалт болон холбоо барих хэсгүүд бий.

## Агуулгыг өөрчлөх

- Танилцуулга, ур чадвар, төслүүдийг `src/App.jsx` дотор засна.
- Өнгө, хөдөлгөөн, responsive дүрслэлийг `src/index.css` болон `src/App.css` дотор засна.
- Холбоо барих имэйл ба GitHub холбоосыг `src/App.jsx` дээрх `contactEmail`, `githubProfile` утгуудаар шинэчилнэ.
- Танилцуулга болон холбоосыг нийтэд тавихаас өмнө өөрийн мэдээллээр баталгаажуулна.

Гаднын загвар эсвэл зургийг хуулж ашиглаагүй. Фонтын хувьд Google Fonts-ийн DM Mono, Manrope ашигласан.
