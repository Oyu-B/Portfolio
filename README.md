# Оюу — хувийн портфолио

React, Vite болон Three.js ашиглан бүтээсэн хоёр хэлтэй, интерактив портфолио.

## Ажиллуулах

```bash
npm install
npm run dev
```

Үйлдвэрлэлийн хувилбар үүсгэх болон локалд үзэх:

```bash
npm run build
npm run preview
```

Кодын алдаа шалгах:

```bash
npm run lint
```

## Файлын бүтэц

| Байршил | Үүрэг |
| --- | --- |
| `src/main.jsx` | React програмыг эхлүүлнэ. |
| `src/App.jsx` | Хуудасны хэсгүүд, хэл ба загварын сонголт, дэлгэрэнгүй цонх, зогсоолын аяллыг удирдана. |
| `src/data/portfolio-content.jsx` | Монгол, англи текст, бүтээл, ур чадвар, холбоо барих мэдээлэл болон зогсоолын дарааллыг хадгална. |
| `src/components/ui/agentic-factory-3d.tsx` | Three.js дүрслэл, камерын удирдлага, зогсоолын үйлдлүүдийг агуулна. |
| `src/components/ui/agentic-factory-3d.css` | 3D талбар болон түүний удирдлагын загвар. |
| `src/App.css` | Портфолионы үндсэн хуудасны загвар. |
| `src/index.css` | Үсгийн фонт, үндсэн өнгө болон бүх хуудсанд нийтлэг суурь загвар. |
| `public/Oyu_Portfolio_Mongolian.pdf` | Монгол хэл дээрх товч намтар. |
| `public/Oyu_Portfolio_English.pdf` | Англи хэл дээрх товч намтар. |

## Агуулга засах

Хуудасны танилцуулга, бүтээл, ур чадварын текстийг `src/data/portfolio-content.jsx`-д шинэчилнэ. Зогсоолын мэдээлэл тэндэх `stationDetails` жагсаалттай ижил дарааллаар байна. 3D дүрслэл болон товчлуурын бүтцийг `agentic-factory-3d.tsx`, харагдах байдлыг `agentic-factory-3d.css`-д засна.
